# 2026-06-17 法术攻击特效 V2 — 时间管理器重构

## 今日主题
解决法术特效播放时序问题，引入 `waitForProjectileEnd()` 时间管理器，确保视觉演出顺序：**瞄准连线 → 弹道飞出 → 命中/爆炸 → 受击 → 飘字 → (死亡)**

## 修改文件清单

### 1. `hooks/useGameState.ts`
**改动：新增 `waitForProjectileEnd()` + commitSpell 改为 async**

- **L17-34**: 新增 `waitForProjectileEnd()` Promise 工具
  - 监听 `SPELL_PROJECTILE_END` 事件
  - 3 秒超时安全网（防止弹道Bug卡死游戏）
- **L1360-1366** (burst 法术路径): `emit START` → **`await waitForProjectileEnd()`** → `executeSpellEffect`
- **L1780-1788** (resolveStack 路径): `emit START` → **`await waitForProjectileEnd()`** → `executeSpellEffect`
- **L1322**: `commitSpell` 改为 `async`

**注意：** `commitSpell` 的调用者在 GameSession/SandboxSession 中是 fire-and-forget（不 await），因此 sync 部分（扣费、清 UI）立即执行，只有伤害部分等待弹道。这是预期的行为。

## 完整演出时序（当前预期）

```
玩家选目标 → VFXLayer 瞄准线从法术图标延展
     ↓
确认目标 → 弹道从画面中心飞向目标 (SpellProjectile, 0.4s)
     ↓
命中 → 爆炸扩散 + 粒子 (SpellProjectile, 0.35s)
     ↓
emit SPELL_PROJECTILE_END
     ↓ ← waitForProjectileEnd()  await 在此等待
     ↓
executeSpellEffect → 游戏扣血 → animState = 'hit'
     ↓
Card GSAP 受击（震动+红闪+裂纹, 0.5s）
     ↓
受伤飘字（Power/Health Delta）
     ↓
（若死亡）→ Card 褪色 → 碎裂 shatter (800ms 后)
```

## 已知问题 / 待 Gemini 修复

### 🐞 BUG-1: `commitSpell` 调用未 await
**文件：** `useGameState.ts` L1623、L1694
**描述：** `commitSpell(card, owner, targets, originalPhase)` 在 `setTimeout` 和 `finalizeTransform` 内被调用时没有 `await`。虽然 fire-and-forget 在实际测试中工作（因为 eventBus + async 函数内 await 仍然有效），但理论上可能有 race condition。

### 🐞 BUG-2: `activeRef` 可能丢弃弹道
**文件：** `SpellProjectile.tsx` L72
**描述：** 当 `activeRef.current` 为 true 时，新 `START` 事件会被静默丢弃。`commitSpell` async 化后，两个 burst 法术不会真正同时触发 projectile，但这个防护在边缘情况下可能丢掉事件的某一次发射。

### 🐞 BUG-3: 爆炸粒子与 timeline 时序
**文件：** `SpellProjectile.tsx` L140-171
**描述：** 粒子通过 `tl.call()` 创建，但每个粒子自己的 `gsap.to()` 独立于 timeline 运行。`tl` 的 `onComplete` 会在粒子动画完成前触发（因为 tl 只等待 `call()` 执行，不等待 inside `gsap.to()` 完成）。目前直接执行 `particlesEl.innerHTML = ''` 清理，但实际上粒子的动画（0.35-0.6s）还没播完。

### 🐞 BUG-4: 死亡触发时机和受击动画重叠
**文件：** `Card.tsx` L348
**描述：** 当 `projectileActive` 从 true→false 时，死亡 timer 设为 800ms，但受击动画播放也同时开始（约 0.5s）。如果受击动画耗时超过 800ms（如飘字动画），死亡 shatter 可能在飘字进行中触发。

### 🐞 BUG-5: VFXLayer 箭头方向在特殊位置可能偏移
**文件：** `VFXLayer.tsx` L153
**描述：** 箭头方向由控制点指向终点计算。对于某些目标位置（如目标在法术图标正上方），控制点偏移逻辑可能导致角度计算异常，箭头指向偏差。

### 🐞 BUG-6: `commitSpell` async 返回值未被消费
**文件：** `useGameState.ts` L2114 (`finalizeSpell: commitSpell`)
**描述：** `actions.finalizeSpell()` 暴露给 UI 层使用。UI 调用 `actions.finalizeSpell(card, player, targets)` 但不 await 返回值。虽然当前功能正常，但如果未来需要知道法术何时结算完毕，UI 层无法获取 Promise。
