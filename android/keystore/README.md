# 安卓签名密钥目录

> ⚠️ **这个目录整体不进仓库**（见根目录 `.gitignore`）。它是你的**唯一身份凭证**。

## 这里该有什么

运行一次 `tools/create-keystore.ps1` 之后，会出现：

```
android/keystore/snowbreak-release.jks      ← 签名密钥文件
android/keystore.properties                 ← 上面一层，自动生成，含密码
```

## 为什么它这么重要

安卓只允许**「同包名 + 同签名」**的包覆盖安装。

| 情况 | 后果 |
|---|---|
| 签名一致 | ✅ 直接覆盖升级，**玩家存档保留** |
| 签名不一致 | ❌ 系统拒绝安装 → 玩家必须**先卸载** → **localStorage 被清空 = 存档全丢** |

**所以：这个文件 + 密码，一旦生成就必须永久保存，永远不能换。**

## 🔴 备份清单（生成后立刻做）

- [ ] 把 `android/keystore/` 整个目录复制到**网盘**（至少一份）
- [ ] 再复制到**U 盘或另一台电脑**（至少一份）
- [ ] 密码单独记在**密码管理器**里
- [ ] 在日记/技术手册里记一句"签名已于某日建立"（**不要写密码**）

> 丢了这个文件 = 你再也无法给已经发出去的版本做升级，
> 所有玩家必须卸载重装、从头开始。**没有补救办法。**

## 重新生成会怎样

不能"重新生成一个更好的"——那等于换了一枚印章，老玩家全部受影响。
**只能一直用它。**
