进攻性：Overwhelm, QuickAttack, Double Attack, Scout, Challenger, Fearsome.

防御/生存：Regeneration, Barrier, SpellShield, Tough, Lifesteal.

控制/干扰：Frostbite, Stun, Silence, Deadly.

战术/资源：CantBlock, Last Breath, Ephemeral, Support.



1. Overwhelm (贯通/碾压)
效果：攻击时，如果攻击力超过阻挡者的生命值，超出的伤害会直接对敌方水晶（Nexus）造成打击。

当前图标设计：红色背景的战锤 (Hammer)。

卡组风格 & 打法：

风格：中速强攻 (Midrange / Stompy)。

打法：利用高攻击力的大型单位，强迫对手进行亏本阻挡。配合加攻击力的法术（如“振奋”），让对手即使挡住了单位，水晶也会被打爆。

2. QuickAttack (先攻)
效果：作为进攻方时，会比阻挡者先造成伤害。如果阻挡者被先攻伤害击杀，则阻挡者无法反击。

当前图标设计：黄色背景的闪电 (Zap)。

卡组风格 & 打法：

风格：快攻/节奏 (Aggro / Tempo)。

打法：依赖高攻击、低血量的单位进行无损换血。非常害怕法术解场，但在生物交换中占尽优势。

3. Regeneration (再生/自动回复)
效果：回合开始时，生命值完全恢复满。

当前图标设计：绿色背景的爱心 (Heart)。

卡组风格 & 打法：

风格：控制/战场 (Control / Board Centric)。

打法：利用这些单位进行持续的阻挡和资源交换。只要不被一击必杀，它们就是无限的城墙。配合加血上限的法术非常强力。

4. Elusive (隐秘/潜行)
预期效果：拥有“隐秘”的单位，只能被同样拥有“隐秘”的单位阻挡。

当前状态：代码中未做阻挡限制检查。

图标建议：紫色背景，幽灵 (Ghost) 或 眼睛 (Eye) 图标。

卡组风格：闪避快攻 (Evasive Aggro)。核心是绕过对方防线直接打脸，逼迫对手和你竞速（Race）。

5. Challenger (挑战者)
预期效果：作为进攻方时，可以指定敌方某个单位来强行阻挡自己（拖拽敌人进入阻挡槽位）。

当前状态：交互层（Battlefield/GameSession）不支持拖拽敌方单位。

图标建议：橙色背景，钩子 (Hook) 或 准星 (Target) 图标。

卡组风格：解场/控制 (Removal / Control)。专门用来猎杀敌方的高价值单位（比如躲在后排的引擎单位或隐秘单位）。

6. Barrier (屏障/圣盾)
效果：抵挡下一次受到的任何伤害。屏障生效一次后消失。

图标设计：金黄色或亮白色的盾牌轮廓，内部发光。

卡组风格：节奏/保护 (Tempo / Protection)。

打法：利用屏障让单位在战斗中白吃对手，或者保护核心英雄（如里芙）生存到升级。这非常适合德玛西亚（光系）的风格。

7. CantBlock (无法格挡)
预期效果：该单位不能被分配为阻挡者。

当前状态：代码中未限制其进入阻挡槽位。

图标建议：灰色背景，破碎的盾牌 (ShieldBan) 或 禁止符号 (Ban)。

卡组风格：纯快攻 (Face Aggro)。这类单位通常身材超模（费用低、属性高），代价是完全放弃防御，只为进攻而生。


8. Lifesteal (吸血)
效果：该单位造成的伤害，会等量转化为我方水晶（Nexus）的生命值恢复。

图标设计：深红色或紫色的水滴/十字架。

卡组风格：控制/拖后期 (Control / Stall)。

打法：专门克制快攻卡组。通过 Buff 吸血单位的攻击力，一口气把血回满，让对手绝望。

9. Last Breath (亡语/遗言)
效果：当该单位死亡时触发特定效果（如：抽一张牌、生成一个 1/1 的小兵、对敌方打 1）。

图标设计：墨绿色或灰色的骷髅头。

卡组风格：献祭/铺场 (Sacrifice / Swarm)。

打法：甚至会主动用自己的法术杀掉自己的单位来触发效果。适合诺克萨斯（暗黑/力量系）风格。

10. Fearsome (威吓/凶恶)
效果：该单位只能被攻击力大于或等于 3 的单位阻挡。

图标设计：深紫色或黑色的鬼脸/面具。

卡组风格：快攻 (Aggro)。

打法：利用对手场上只有 1/1 或 2/2 的小兵时，直接让小兵无法格挡，从而造成伤害。这是对付“铺场流”卡组的利器。

11. Frostbite (冻结)
效果：将一个单位的攻击力在本回合设为 0。（这通常是一个法术效果，或者单位进场效果）。

图标设计：蓝白色的雪花 (Snowflake)。

卡组风格：中速控制 (Midrange Control)。

打法：在战斗中瞬间让对方的大哥变成废人，实现无伤阻挡或无伤进攻。非常讲究出牌时机。


12. Scout (侦察)
效果：当拥有“侦察”的单位首次发起进攻时（且本次进攻只有侦察单位），如果我方没有进攻机会（Attack Token），则不会消耗进攻机会；或者在攻击结算后，重新获得一次进攻机会。

简单来说：侦察单位先打一轮，打完后，我们可以发起全员的第二轮进攻。

图标设计：墨绿色或深蓝色的 指南针 或 望远镜。

卡组风格：节奏/多段攻击 (Tempo / Multi-Attack)。

打法：通过每回合发起两次进攻来给对手施加巨大的格挡压力。配合“攻击时触发效果”的英雄或单位非常强力。

13. Ephemeral (瞬息/幻象)
效果：该单位在打击一次后，或在回合结束时，会自动死亡。

图标设计：半透明的 幽灵 或 正在消散的沙漏，带有一点紫色雾气。

卡组风格：召唤/献祭流 (Summon / Sacrifice)。

打法：这类单位通常费用极低但身材极度超模（比如 1费 5/5）。你是把它们当作“一次性导弹”扔出去解场的，或者配合“亡语 (Last Breath)”效果使用。

14. Stun (眩晕)
效果：将一个单位移出战斗（如果它正在进攻或格挡），并且在本回合内该单位无法再次进攻或格挡。

图标设计：黄色的 螺旋晕眩符号（像漫画里被打晕那样）。

卡组风格：控制/拖延 (Control / Stall)。

打法：不通过伤害杀敌，而是通过“控制”让敌方的大哥罚站。非常克制单核（依靠一个强力大哥）卡组。

15. Tough (坚韧)
效果：该单位受到的所有伤害 -1（例如受到 1 点伤害变为 0，受到 3 点变为 2）。

图标设计：银灰色的铠甲或岩石纹理。

卡组风格：抗压/站场 (Anti-Aggro / Board)。

打法：这类单位是 1/1 小兵和低费法术（如“暗箭 打1”）的克星。虽然看起来减伤不多，但在积少成多中能赚取巨大的卡差。

16. Double Attack (连击/二刀流)
效果：进攻时，该单位会打击 两次。

第一次打击：拥有“先攻”时机（在阻挡者反击前）。

第二次打击：普通时机（和阻挡者互殴）。

图标设计：两把交叉的 匕首 或 双重闪电。

卡组风格：OTK (One Turn Kill) / 斩杀。

打法：这是最暴力的关键词。如果你给一个高攻击力的“连击”单位加上“贯通 (Overwhelm)”，它能瞬间打出毁灭性的伤害。

17. Support (支援)
效果：当该单位进攻时，给予它 右边 的友军一个增益效果（例如 +1/+1，或给予屏障）。

图标设计：握手 或 向上的箭头辅助线。

卡组风格：铺场/阵型 (Board / Formation)。

打法：非常讲究卡牌在战场上的摆放位置（我们现在的架构支持位置区分）。你需要保护好辅助单位，让它不断给打手输送 Buff。

18. Deadly / Deathtouch (致命/剧毒)
效果：该单位造成的任何伤害（哪怕只有 1 点），都会直接消灭目标单位（无视剩余生命值）。

图标设计：滴着绿色液体的 骷髅头 或 蛇牙。

卡组风格：以小博大 (Anti-Big)。

打法：用 1/1 的小蜘蛛去换掉对手 10/10 的巨龙。这是低费卡组对抗后期卡组的终极威慑手段。

19. SpellShield (法术护盾/魔免)
效果：抵挡下一次敌方对该单位施放的法术或技能效果。护盾生效一次后消失。

图标设计：紫色的 魔法球 或 破碎的符文护盾。

卡组风格：保护核心 (Protect the Castle)。

打法：这是英雄单位最好的保命符。让对手的解场法术（如“复仇：消灭一个单位”）完全浪费掉，极大地破坏对手的节奏。

20. Silence (沉默)
效果：移除一个单位上的所有关键词、法术效果和文本描述（只保留原始的身材数值）。

图标设计：被打叉的 嘴巴 或 禁止符号。

卡组风格：反制/针对 (Tech / Counter)。

打法：当对手花了一万费把一个单位养成了 20/20 且带有“贯通、吸血、护盾”的怪物时，你一张“沉默”把它变回 1/1 的白板。这是最搞心态的关键词。

21. Berserk (狂暴 / 暴怒)
效果：当该单位击杀敌方单位并存活时，自身获得 +1/+1。

图标设计：燃烧的 红色眼睛 或 破碎的锁链。

卡组风格：滚雪球/中速 (Snowball / Midrange)。

打法：通过法术（如“单挑”）或有利的格挡，让狂暴单位不断吃掉对手的小兵，身材越养越大，最终变成对手无法处理的 Boss。适合龙族或狂战士主题。

22. Cleave (顺劈 / 溅射)
效果：该单位在进攻时，会对阻挡者 左边和右边 的敌方单位造成 1 点（或 X 点）伤害。如果没人阻挡，则不对邻居造成伤害（或对水晶造成额外伤害）。

图标设计：横向挥舞的 弯刀轨迹 或 三道抓痕。

卡组风格：反铺场 (Anti-Swarm)。

打法：专门惩罚喜欢铺满一排小兵的对手。利用位置学，强迫对手在这个单位对面留空，或者牺牲旁边的关键单位。

23. Thorns (荆棘 / 反伤)
效果：当该单位受到攻击伤害时，对攻击者造成 1 点伤害。

图标设计：缠绕的 带刺藤蔓 或 仙人掌。

卡组风格：防御/抗快攻 (Defensive / Anti-Aggro)。

打法：这是低血量高攻击力刺客（如“先攻”单位）的克星。哪怕你的荆棘单位攻击力是 0，也能换掉对手的 1 血刺客。

24. Vanguard (先锋 / 破晓)
效果：如果是本回合你打出的 第一张 牌，触发额外效果（如 +2/+2 或抽一张牌）。

图标设计：升起的 太阳 或 金色的剑锋。

卡组风格：按费拍怪/节奏 (Curvestone / Tempo)。

打法：鼓励积极主动的打法。你需要精心规划每回合的行动顺序，确保强力的先锋卡是第一个打出的。

25. Ambush (伏击 / 连击)
效果：如果是本回合你打出的 非第一张 牌（即之前已经打出过其他牌），触发额外效果。

图标设计：阴影中的 匕首 或 月亮。

卡组风格：组合技 (Combo)。

打法：通常配合低费法术（0费或1费）作为“启动器”，然后拍出伏击单位赚取巨大收益。考验手牌管理能力。

26. Plunder (劫掠)
效果：如果本回合你已经对敌方水晶（Nexus）造成过伤害，打出该牌时触发额外效果。

图标设计：装满金币的 钱袋 或 海盗钩子。

卡组风格：抢血/快攻 (Burn / Aggro)。

打法：利用“贯通”单位或直接伤害法术（如“暗箭”）先打脸，激活劫掠效果。这会让你的卡组极具侵略性。

27. Exposed (暴露 / 易伤)
效果：拥有此关键词的单位，可以被敌方任意单位 挑战 (Challenger)（即强迫其进行格挡）。

注：这是一个负面关键词，通常出现在超模单位身上作为代价，或者是作为法术 Debuff 施加给敌人。

图标设计：破碎的 瞄准镜 或 被撕裂的护甲。

卡组风格：高风险高回报 (High Risk High Reward)。

打法：你获得了一个 2费 5/5 的强力单位，但对手可以用最弱的 1/1 把你拉走，让你无法阻挡关键进攻。

28. Shroud (帷幕 / 魔免)
效果：该单位无法被敌方的法术或技能 指定为目标。（类似于永久的 SpellShield，但通常不能抵挡 AOE）。

图标设计：隐约可见的 斗篷 或 迷雾。

卡组风格：单核强化 (Voltron / Buff)。

打法：因为对手无法用法术解掉它，你可以放心地把所有的 Buff（+攻击、+生命）都贴在这个单位身上，造出一个无敌的怪物。

29. Immobile (固定 / 哨兵)
效果：该单位无法进攻，也无法格挡。（通常作为提供被动光环的“建筑”或“引擎”）。

图标设计：灰色的 石塔 或 地基。

卡组风格：引擎/组合技 (Engine / Combo)。

打法：它占一个格子，不参与战斗，但可能每回合给你一张法术，或者给友军加攻。你需要保护它，或者利用能够让它“动起来”的法术（如“沉默”自己）。

30. Reborn (复生)
效果：该单位第一次死亡时，不会移出游戏，而是移除此关键词并以 1 点生命值复活。

图标设计：金色的 凤凰羽毛 或 破碎重组的盾牌。

卡组风格：赖场/粘性 (Sticky Board)。

打法：非常克制依靠单次高伤害解场的对手。配合“亡语”效果可以触发两次，非常强力。

31. Execute (处决)
效果：攻击或格挡时，如果目标的生命值低于该单位的攻击力（或者目标已受伤），则直接消灭目标（无视目标的护盾或无敌）。

图标设计：红色的 断头台 或 X型斩击。

卡组风格：解场/控制 (Removal)。

打法：专门用来处理高血量的坦克单位。配合全场打 1 的 AOE 法术，可以让处决单位收割全场。

32. Sniper (狙击)
效果：当该单位发起进攻时，对阻挡者造成 1 点伤害（在战斗结算前）。

图标设计：十字准星 或 子弹。

卡组风格：削弱/快攻 (Ping / Aggro)。

打法：用来破除对手的“屏障 (Barrier)”，或者直接点杀对手的 1 血单位，让其无法进行有效阻挡。

33. Volatile (易碎 / 瞬逝)
效果：如果该牌在回合结束时仍在手牌中，则自动弃置。

图标设计：正在燃烧的 纸张 或 沙漏。

卡组风格：资源生成 (Resource Generation)。

打法：这通常出现在由其他卡牌生成的强力“衍生卡”上。迫使玩家必须在当回合使用它，增加了决策的紧迫感。

34. Echo (回响)
效果：当打出该牌时，在手牌中生成一张该牌的 瞬息 (Volatile) 复制品（通常费用依然需要支付）。

图标设计：波纹 或 重叠的卡牌。

卡组风格：铺场/法术连击 (Swarm / Spells)。

打法：只要你有足够的法力，一张牌可以当两张用。非常适合后期爆发或快速铺满备战席。

35. Impact (冲击)
效果：当该单位进攻并进行打击时（无论是否被阻挡），对敌方水晶造成 1 点伤害。如果该单位有层数（冲击 x2），则造成 2 点。

图标设计：撞击地面的 陨石坑 或 红色火花。

卡组风格：攻城/直伤 (Siege / Burn)。

打法：不管对手怎么防守，只要我进攻了，就能蹭掉对手的血量。积少成多，给对手造成巨大的心理压力。

36. Channel (充能)
效果：当该单位召唤时，回复 1 点 法术法力 (Spell Mana)。

图标设计：蓝色的 水滴 或 法力水晶。

卡组风格：法术控制 (Spell Control)。

打法：让你在铺场的同时，还能留出法力值来施放反制法术（如“格挡”或“Buff”）。让卡组运转更加丝滑。
