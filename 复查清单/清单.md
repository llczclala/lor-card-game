## 图例

| 列 | 含义 |
|----|------|
| **注册层** | 卡牌在 `cards.ts` 中定义，效果 key 指向 `effectRegistry.ts` 中存在的条目 |
| **玩家逻辑层** | 玩家打出时，`effectProcessor.ts` 能正确处理其效果 |
| **AI侧逻辑层** | AI 有对应的决策逻辑（单位用通用逻辑，法术用 Pattern 引擎） |
| **AI侧使用** | AI 在实际对局中会打出这张卡牌 |
| **🎯 AI侧阵营判定** | **新增验证维度**：AI 打出时，效果的"我方"/"敌方"判定是否正确 |
| | `context.owner` 正确映射 → 如 "对己方所有单位造成1点伤害" 确实打到 AI 自己的单位 |
| | `targetAllAllies` / `targetAllEnemies` 等参数按 `context.owner` 分支正确选择 bench |
| | 无硬编码 `'player'` 字符串导致 AI 侧效果方向错误 |
